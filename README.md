# 🏋️ FITLOG - Workout Planner

A simple fitness application built with Next.js to track daily workout routines, exercise duration, and burned calories.

## 🌟 Key Features

- **Today's Plan & Saved Lists**: Organize exercises for today or save them for later.
- **Exercise Stats**: Automatically calculates total exercises, minutes, and calories.
- **Sorting**: Sort exercises by duration, calories, or name.
- **Notifications**: Instant feedback using react-toastify when adding, completing, or removing exercises.

## 🛠️ Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS & Lucide Icons
- **State**: React Context API
- **Toasts**: React Toastify
